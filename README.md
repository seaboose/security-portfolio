# Sebastian “seaboose” Marquez — Information Security

Interactive portfolio featuring Surge and StudyStep, project walkthroughs, and education.

Built with static HTML, CSS, JavaScript, and local visual assets. Hosted on GitHub Pages with the custom domain `seaboose.me`.

## Updating

- `project-catalog.json` controls project descriptions, verified app versions, and walkthrough steps.
- `course-catalog.json` controls the course outline and standing.
- `assets/profile-sections.html` is the shared profile source; keep the matching sections in `index.html`, `act.html`, and `learn.html` synchronized using the working project's build script.
- Review app changes against the installed release before changing screenshots or demonstrations.
- Publish reviewed static files to `main`; GitHub Pages serves the repository root.

Map traffic and walkthrough animations are illustrative. Source links and release references are included in the site.
